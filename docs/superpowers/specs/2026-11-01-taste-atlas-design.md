# 게이머 유형 도감과 상세 카드

사용자는 전체 캐릭터 도감에서 유형별 상세 카드로 이동하는 구성과 기존 마을에 맞춘 픽셀아트 제작을 승인했다.

## 설계
- 새 경로 `/[locale]/taste`는 16개 캐릭터를 보여 주는 도감이다. 축 필터, 검색, 유형별 상세 링크를 제공한다.
- `/[locale]/taste/[code]`는 캐릭터 초상화, 코드와 네 성향, 한 줄 설명, 상세 설명, 추천 태그, 원작 Steam 링크, 공유 링크를 제공한다.
- 그림은 실제 게임 캐릭터를 각각 별도 PNG/WebP로 제작한다. 코드, 게임명, 설명은 이미지에 넣지 않는다.
- 백엔드에 준비된 `taste-v1.json`의 16유형 문구를 프론트 스냅샷으로 사용한다. 네트워크가 없어도 도감과 공유 링크를 열 수 있다. 백엔드 파일은 수정하지 않는다.
- 성향 수치는 실제 테스트 결과가 없으면 표시하지 않는다. 유형 도감 방문을 테스트 결과로 표현하지 않는다.
- 기존 7라운드 테스트를 유지한다. 랜딩 보조 링크에 유형 도감을 추가하고 기존 경로와 추천 기능을 보존한다.
- 새 12문항 테스트와 추천 API 연결은 이번 범위에 포함하지 않는다. 현재 API 구현이 진행 중이며 사용자는 도감과 상세 카드 제작을 선택했다.
- 기존 야간 남색, 목재, 등불, Galmuri 굵은 글꼴, 각진 선을 유지한다. Hallmark는 현재 화면 평가와 새 화면의 품질 점검에 사용하고 기존 랜딩을 임의로 재설계하지 않는다.
- 캐릭터 대응은 비공식 취향 비유다. 제작된 팬아트는 이용허락 확인과 구분하고 권리 검토 상태를 기록한다.

## 검증
16개 코드의 완전성, 필터 및 검색, 유효하지 않은 코드, 양 언어 상세 화면, 공유 성공과 실패, 이미지 누락을 검증한다. 전체 테스트, lint, production build와 실제 브라우저 모바일/데스크톱 검증을 수행한다.
