## 제작 방식과 상태
내장 image_gen 도구를 사용했다. API 키나 별도 유료 API를 사용하지 않았다. 생성 원본은 .codex/generated_images에 보존하고 프로젝트 public/images/taste에 복사했다.

비공식 팬아트다. 이미지 생성 가능 여부와 공개 이용허락은 다르며 이 문서는 이용 허락 확인서가 아니다. 사용자의 지시에 따라 미확인 후보도 개발용 목록에 유지했다. 모든 캐릭터는 해당 원작의 권리자에게 귀속된다.
